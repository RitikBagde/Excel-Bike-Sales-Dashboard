# Excel Bike Sales Dashboard

An interactive **Excel dashboard project** created to analyze bike sales, customer demographics, purchasing behavior, and sales trends.

The project demonstrates practical skills in **Excel data cleaning, data analysis, Pivot Tables, and dashboard creation**.

---

## Project Overview

This project analyzes a bike buyers dataset containing customer demographic and purchasing information.

The raw data was cleaned and transformed before creating Pivot Tables and an interactive dashboard to identify useful patterns in customer behavior and bike purchases.

The final dashboard provides a visual overview of the dataset and helps understand which customer groups are more likely to purchase bikes.

---

## Objectives

The main objectives of this project were:

* Clean and prepare the raw dataset for analysis
* Analyze customer demographics
* Understand bike purchasing behavior
* Identify patterns between age, income, marital status, education, and bike purchases
* Create Pivot Tables for data analysis
* Build an interactive Excel dashboard
* Present insights through charts and visualizations

---

## Workbook Structure

The Excel workbook contains the following sheets:

### 1. `bike_buyers`

Contains the original/raw dataset used for the analysis.

### 2. `Working Sheet`

Contains the cleaned and prepared data used for analysis.

### 3. `Pivot Table`

Contains Pivot Tables created to analyze different aspects of the dataset.

### 4. `Dashboard`

Contains the final interactive dashboard with charts and visualizations.

---

## Dashboard

The dashboard provides a visual summary of bike purchasing behavior across different customer characteristics.

It can be used to explore relationships between:

* Gender and bike purchases
* Age groups and bike purchases
* Income and purchasing behavior
* Commute distance and bike purchases
* Education and bike purchases
* Customer demographics and purchasing patterns
